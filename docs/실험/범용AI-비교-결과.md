# 범용 AI 비교 실험 결과 (개발기획서 1.5·14장, 개선사항 4)

`scripts/ai_compare.py`로 측정한 값이다. 원본 응답 64개는 `docs/실험/범용AI-비교-원본/`에 있고, 모두 합성 데이터이며 사용자 정보는 쓰지 않았다.

## 한 줄 결론

**"범용 AI는 수치 계산이나 일관성에서 틀린다"는 주장은 이 실험으로 뒷받침되지 않았다.** 기획서 1.5가 "결과가 나오기 전에는 단정하지 않는다"고 한 대로, 측정값을 그대로 적는다. 정리하면 이렇다.

| 항목 | 결과 | 선비의 차별점으로 쓸 수 있나 |
|---|---|---|
| 전환점 정확도 ("몇 %가 되면 1위가 바뀌나") | Claude·GPT 모두 12/12 정확(오차 0.00%p), 3회 반복도 같은 값 | **없음.** 점수표와 계산 규칙을 글로 주면 최신 모델은 정확히 푼다 |
| 같은 답변에서 가중치 추정의 일관성 | 4명 × 5회 = 20회 중 대부분 같은 값. 다만 GPT는 한 번 완전히 다른 값(성능 41%)을 냈고 Claude도 한 번 다른 값을 냈다. 선비는 시드만 바꿔도 표준편차 0.6%p 안쪽 | **약함.** "가끔 튄다" 정도다 |
| 가중치 정확도(MAE) | 선비 6.1%p, Claude 7.3%p, GPT 7.7%p | **방향은 선비가 낫지만 사용자 4명이라 우연일 수 있다** |

## 해석 (솔직하게)

1. **이번 실험은 범용 AI에 유리하게 짰다.** 슬라이더 한 칸이 중요도 비율 e^0.3배라는 모델, 점수표, 계산 규칙을 프롬프트에 전부 적어 줬다. 실제 대화에서는 사용자가 "가격이 제일 중요해요" 정도로만 말한다. 그 입력에서는 범용 AI가 가중치를 지어내야 하므로 이 실험보다 불리하다. 하지만 **이번에 그 경우는 재지 않았다.**
2. 두 모델은 도구 없이도 추정이 선비 엔진과 같은 방향의 값(예: 사용자 2에서 22/5/30/30/12 대 선비 23/2/36/30/9)에 도달했다. 모델이 풀이를 안다는 뜻이고, 이 과제 자체에서는 선비가 계산에서 이기지 않는다.
3. 선비가 구조적으로 앞서는 것은 이번에 **재지 않은** 곳에 있다. (a) 다음 질문을 정하는 일 — 랜덤 질문 대비 같은 정확도에 더 적은 질문(`docs/실험/시뮬레이션-결과-자바.md`: 진로형 7.2문항 → 5.3문항), (b) 입자 4,000개로 만든 불확실성(구간·1위일 확률·안정성), (c) 결정의 고정된 기록·확정 시점 스냅샷. 범용 AI는 이번에도 점 추정만 냈다(구간을 요청하지 않았다).
4. 발표에서는 "범용 AI는 계산이 틀린다"가 아니라 **"계산은 비슷하게 하지만 질문을 설계하고 불확실성을 숫자로 약속하는 일은 선비의 엔진이 맡는다"**로 말해야 이 실험과 맞는다.

## 아직 안 한 것

- 기획서 1.5의 세 번째 실험(질문 효율: 챗봇 인터뷰 vs 선비 질문)은 사람이 챗봇을 상대로 반복 대화해야 해서 하지 않았다. 대신 선비 쪽은 EIG 대 랜덤으로 시뮬레이션했다.
- 사용자가 자연어로만 말하는 입력(수치 없음), 기준 개수가 더 많은 문제, 모델 난이도를 낮춘 경우(작은 모델)는 재지 않았다.
- 표본이 작다: 사용자 4명, 전환점 문제 4개. 평균 차이를 통계적으로 주장할 수 없다.

## 한계

- 모델 이름과 설정은 아래 "실험 조건"에 적었다. "도구 없이"는 Claude는 도구 목록을 비워 확실히 지켰고, GPT는 코드 실행을 쓰지 말라고만 지시했다. 저장한 로그는 끝 200자뿐이라(32개 모두 코드 실행 흔적 없음) 실행 여부를 완전히 증명하지는 못한다. 다시 돌릴 때는 전체 로그를 남기도록 고치는 것이 좋다.
- "Claude"는 이 저장소 작업에 쓴 모델과 같은 계열이다. 결과를 유리하게 만들 수단은 없었으나(프롬프트와 정답은 스크립트가 고정), 독립 검증을 위해 `scripts/ai_compare.py`를 다시 돌려 볼 수 있다.

## 실험 조건

- 모델: Claude (claude-sonnet-5-5), GPT (gpt-5.6-sol, 추론 medium). 도구·코드 실행 없이 답하게 했다(Claude는 도구 목록을 비웠고, GPT는 읽기 전용 샌드박스에서 코드를 쓰지 말라고 지시).
