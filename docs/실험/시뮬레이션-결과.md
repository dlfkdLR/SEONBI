# 엔진 시뮬레이션 결과 (개발기획서 14장)

`backend/notebooks/simulation.py`를 실제로 돌려 얻은 수치다. 아래 표는 스크립트 출력을 그대로 옮겼다. 다시 만들려면 `backend/`에서 다음을 실행한다.

```
python notebooks/simulation.py --scenario purchase --users 200            # 시드 42, ε=0
python notebooks/simulation.py --scenario career   --users 200
python notebooks/simulation.py --scenario purchase --users 200 --noise 0.1
python notebooks/simulation.py --scenario career   --users 200 --noise 0.1
```

시나리오 하나(200명 × 두 전략)에 약 3분 걸린다.

## 1. 실험 설정

**가상 사용자**: 정답 가중치 `w* ~ Dirichlet(1,…,1)`을 하나 뽑고, 질문이 나오면 엔진의 우도(5.3)로 응답 분포를 계산해 그 분포에서 응답을 뽑는다(슬라이더 11값, A/B 2값). `--noise ε`를 주면 확률 ε로 응답을 응답 후보 중 균등 무작위로 바꾼다. 이때 엔진은 노이즈를 모르는 채 그대로 추정한다(모형 불일치).

**시나리오**

| 이름 | 기준 5개 | 선택지 4개 |
|---|---|---|
| 구매형 | 가격·무게·배터리·저장공간(숫자형 4), 성능(단계형 L=5) | 노트북 4종 |
| 진로형 | 흥미(순위 입력), 적성(L=4)·전망(L=5)(단계형), 통학시간·등록금(숫자형) | 학과 4개 (`tests/engine/test_simulation.py`의 `_career()`와 같은 값) |

**질문 선택 전략** (둘 다 같은 사용자, 같은 추정기 `posterior.fit`, 같은 종료 규칙 `stopping.should_stop`)

- `eig`: 실제 엔진. `next_question`(초기 슬라이더 사슬, 미등장 기준 우선, EIG 최대, 상황형 할당, 연속 금지 규칙 포함).
- `random`: 활성 기준 중 무작위 쌍을 고르고, 유형을 `slider_pair` / `ab_criteria` / `ab_scenario` 중 균등하게 고른다. `ab_scenario`는 `build_scenarios`로 만든 후보 중 하나이며 순위 입력 기준이 낀 쌍에서는 만들어지지 않으므로 그때는 앞의 두 유형 중에서 고른다. EIG와 선택 규칙은 쓰지 않는다.

**종료 규칙**: 5.10 그대로(`CONFIDENT` P_best ≥ 0.85, `LOW_INFO_GAIN` EIG < 0.03 bit, `MAX_QUESTIONS` = max(6, 2K), 최소 3문항). 확신도 계산은 두 전략 모두 엔진의 사후분포를 쓴다.

**같은 질문 수 비교**: 종료 규칙과 별개로, 각 사용자의 궤적에서 답변 3, 5, 7개 시점의 사후 평균을 따로 평가한다(종료 규칙이 더 일찍 끝내도 7개까지 계속 진행해 기록).

**지표** (모두 사용자 평균 ± 표준오차)
- MAE: 기준별 |추정 평균 가중치 − 정답 가중치|의 평균.
- 1위 적중률: 추정 평균 가중치로 계산한 1위 선택지 = 정답 가중치로 계산한 1위 선택지.
- 질문 수: 종료 시점까지의 답변 수.

**고정 파라미터 (코드 버전과 무관하게 재현에 필요한 값)**: 입자 수 N=4000, 사전분포 Dirichlet(1), 사용자 수 200, 기본 시드 42. 사용자 i의 정답 가중치는 `default_rng([42, 시나리오번호, i, 0])`(구매형 0, 진로형 1), 추정기 시드는 `(42·1000003 + 시나리오번호·10007 + i) mod 2^31`, 응답 난수는 `default_rng([42, 시나리오번호, i, 1 또는 2])`(eig=1, random=2). 두 전략은 같은 정답 가중치·같은 추정기 시드를 쓰는 짝 비교다. c=0.3, σ=0.6, β=8, λ=1은 5.13의 초기값.

## 4. 해석

**EIG가 분명히 나은 점**
- 같은 질문 수에서 MAE는 4개 조건(구매·진로 × ε 0·0.1), 3·5·7문항 12개 칸 모두에서 EIG가 낮다. 차이는 0.010~0.027이고, 짝 비교 표준오차(0.003~0.004)의 3~9배다. 상대 크기로는 MAE가 약 10~30% 작다.
- "더 적은 질문으로 같은 정확도": 구매형(ε=0)에서 EIG 3문항의 MAE 0.086은 랜덤 7문항의 0.092보다 낮다. 진로형(ε=0)에서는 EIG 5문항 0.070이 랜덤 7문항 0.084보다 낮다. 다만 진로형 EIG 3문항(0.087)은 랜덤 7문항(0.084)에 못 미친다. 즉 "질문 수를 절반 안팎으로 줄여도 MAE가 같거나 낮다"는 수준이지 모든 구간에서 성립하는 것은 아니다.
- 종료 규칙을 적용하면 EIG가 더 일찍 끝난다(구매형 4.45 vs 5.12, 진로형 5.71 vs 7.55 문항). 그런데도 MAE는 낮고 1위 적중률은 같거나 높다. 진로형에서 랜덤이 질문을 많이 쓰는 것은 순위 입력 기준이 낀 쌍에서 상황형을 못 만들고, 정보가 적은 질문이 섞여 확신도가 천천히 오르기 때문으로 보이지만 이 원인을 따로 분리해 확인하지는 않았다.

**EIG가 낫다고 말하기 어려운 점**
- 1위 적중률 차이는 작고 표준오차(0.015~0.034) 안에 들어가는 칸이 많다. 구매형 3문항(0.875 vs 0.840), 진로형 ε=0.1의 3문항(0.670 vs 0.690, 랜덤이 오히려 높음)과 7문항(0.770 vs 0.780), 구매형 ε=0.1의 3문항(둘 다 0.845)은 차이가 없거나 랜덤 쪽이다. 노이즈가 있을 때의 적중률 우위는 이 실험으로는 입증되지 않는다. 적중률 우위가 비교적 뚜렷한 것은 ε=0의 구매형 7문항(0.940 vs 0.830)과 진로형 5문항(0.820 vs 0.740)이다.
- 종료 규칙을 적용한 적중률(구매형 0.950 vs 0.855)은 질문 수도 달라서 같은 조건 비교가 아니다. 같은 질문 수 표를 근거로 삼는 것이 맞다.
- 진로형의 절대 적중률은 EIG도 7문항에서 0.84로 높지 않다. 정답 가중치를 Dirichlet(1)로 뽑으면 두 선택지의 점수가 거의 같은 사용자가 많아서, 가중치를 꽤 정확히 알아도 1위가 뒤집힐 수 있다.

**한계**
- ε=0에서는 가상 사용자가 엔진이 가정한 바로 그 모형으로 답하므로, 실제 사람(c, σ, β가 다르거나 일관성이 낮은 응답)보다 유리한 조건이다. ε=0.1은 단순한 모형 불일치 실험일 뿐 실제 응답 분포를 대표하지 않는다. 절대 수치는 파일럿(14장) 결과로 다시 확인해야 한다.
- `eig`는 EIG 하나가 아니라 초기 슬라이더, 미등장 기준 우선, 상황형 할당, 연속 금지 규칙을 포함한 엔진 전체다. 따라서 이 결과는 "엔진 전체의 질문 선택이 랜덤보다 낫다"를 보여 주며, EIG 항목만의 기여를 분리하지는 않는다.
- 랜덤 기준선은 실제 설문처럼 고정 순서로 묻는 방식이 아니라 매번 무작위 기준 쌍을 묻는 방식이다. 선택지 4개·기준 5개 두 문제에서만 확인했다.
